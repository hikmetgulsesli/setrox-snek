# Setrox Snek

A classic Snake game built with React, TypeScript, and Tailwind CSS v4.

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Type check
npm run typecheck

# Build for production
npm run build
```

## Tech Stack

- Vite + React + TypeScript
- Tailwind CSS v4
- Google Fonts (Space Grotesk + DM Sans)
